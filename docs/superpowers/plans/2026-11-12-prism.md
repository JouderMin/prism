# PRISM 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 JUCE 8 + CMake + C++20 做出 PRISM：7 段光电压缩器，AU/VST3/Standalone 三格式，macOS arm64。

**Architecture:** 线性相位 FIR 分频（2049 抽头，减法得 7 段），每段独立检测器、光强、光敏电阻、反馈增益与 auto-gain，求和后混音。构建用 `juce_add_plugin`，不写自定义打包规则。

**Tech Stack:** JUCE 8.0.7（vcpkg）、CMake 3.28+、Ninja、C++20、`juce::UnitTest`、`juce::dsp::FFT`。

**Spec:** `docs/superpowers/specs/2026-11-12-prism-design.md`

## Global Constraints

- 平台：macOS arm64，只此一个。
- 标准：C++20，`CMAKE_CXX_EXTENSIONS OFF`。
- 内存：禁止 `new`、`delete`、`malloc`、`free`；用 `std::unique_ptr`、`std::vector`、`std::array`、`juce::OwnedArray`。
- 音频线程零分配、零锁、零 I/O；回调标 `noexcept`。
- 延迟：1152 样本（分频 1024 + 处理块 128），用 `setLatencySamples` 上报。
- 参数：只有 AMOUNT、SPECTRUM、MIX、INPUT、OUTPUT 五个，逐段增益是编译期常量。
- 标识：厂商码 `Stgz`，AU type `aufx`，subtype `Prsm`，bundle id `com.stargazer.prism`，版本 0.1.0。
- 分频点：150、500、1200、3000、8000、14000 Hz，2049 抽头，Kaiser β = 8。
- 光电链路常量照 spec 5.3、5.4 的表取值，不得在本计划里另定。

## Review Focus

- 宿主给单声道缓冲或非立体声总线时，插件必须拒绝而不是崩溃（总线只支持立体声）。
- 采样率变化（44.1/48/96 kHz）后延迟与滤波器必须重建，不能沿用旧系数。
- 静音输入必须输出静音，不得出 NaN 或次正规数拖慢 CPU。
- 离线渲染时延迟补偿必须生效，否则不能用于 bounce。
- 编辑器关闭再打开、状态保存再加载后，声音必须完全一致。

- [ ] **Step 4: 实现 `designLowpass`**

- [ ] **Step 3: 写 `BandTable.h`**

7 条常量，逐字段照 spec 5.4 的表：`tauLdrSeconds`（10/18/28/38/50/65/80 ms 换算成秒）、`gamma`（0.9/0.95/1.0/1.05/1.1/1.15/1.2）、`sensitivityDb`（−18.14/−14.33/−13.05/−12.22/−11.26/−10.72/−10.67）、`targetSlope`（1.5/1.8/2.0/2.2/2.5/2.8/3.0）。

- [ ] **Step 4: 实现 `OptoBand`**

按 spec 5.3：

- 检测：带内输入整流后一阶包络，attack 10 ms、release 60 ms，插值权重用 `1 − exp(-1/(tau·fs))`（写成 `exp(-1/(tau·fs))` 会变成近瞬时跟踪）。前馈拓扑，不取压缩后信号。
- 灵敏度：`env' = env · 10^(sensitivityDb/20)`，值来自 `BandTable`。
- 光强：`d = A·(env'/ref)^1.6`，`ref = 10^(-18/20)`，`A = 10^(driveDb/20)`，`d` 下限 1e−12。
- 电阻：`R = R_dark/(1 + (d/d0)^γ)`，`R_dark = 150e3`、`d0 = 1`；再以 `tauLdrSeconds` 一阶跟随。
- 增益：`g = (R_s + R)/(R_s + R_dark)`，`R_s = 10e3`，夹到 `[10e3/160e3, 1]`。暗态 g = 1，全亮 −24.1 dB。
- 方向检查：光强升 → R 降 → g 降，输出被压。`g` 夹子是防 NaN 的必需项。

```sh

```

预期：3 条用例全过。斜率偏差超 0.5 时调 `gamma` 与指数 1.6 的取舍，不改表内目标值。
